API Endpoints Reference

Base URL: http://localhost:8080/api

Available Endpoints:
• GET /users - List all users
• GET /patrol-clients - List patrol clients
• GET /spots - List all QR spots
• GET /timestamps - View audit logs
• GET /patrol-spot-timestamps - View patrol activities

All endpoints require HTTP Basic Authentication with your credentials.
